<h1><strong>MORSE CODE</strong></h1>

<h2>Definition:</h2>
<p>Morse code is a telecommunications system that encodes text characters as standardized sequences of short and long signals called dots (dits) and dashes (dahs). </p>

<h2>How It Works:</h2>
<p>
  <ul>
    <li>
      <b>Dots and Dashes</b>: A dot lasts for one basic time unit, while a dash lasts for three time units.
    </li>
    <li>
      <b>Spacing Rules</b>:
      <ol>
        <li>
          The space between individual components (dots/dashes) of a letter is 1 unit.
        </li>
        <li>
          The pause between letters within a word is 3 units.
        </li>
        <li>
          The pause between complete words is 7 units.
        </li>
      </ol>
    </li>
  </ul>
</p>

<h2>Frequency Design</h2> 
<p>
  Frequently used letters have shorter combinations (for example, the letter "E" is a single dot).
</p>

<h2>History</h2>
<p>
  <ul>
    <li>
      <b>Invention</b>: Developed in the 1830s and 1840s by Samuel Morse and Alfred Vail for use with the electrical telegraph.
    </li>
    <li>
      <b>Evolution</b>: Originally recorded as indentations on paper tape, it later shifted to audio clicks and radio tones.
    </li>
  </ul>
</p>

<h2>Common Examples</h2>
<p>
  <b>SOS (Distress Signal)</b>:
  <ul>
    <li>
      ... --- ... : (three dots, three dashes, three dots)
    </li>
    <li>
       A: .- (dot-dash)
    </li>
    <li>
      B: -... (dash-dot-dot-dot)
    </li>
  </ul>
</p>
